# Security policy

This repository contains benchmark evidence and synthetic model outputs. It does not include credentials or account data.

If you find a leaked secret, personal identifier, unintended confidential source, or executable security issue, do not open a public issue containing the sensitive value. Use GitHub's private vulnerability reporting or contact the repository owner through the address listed on their GitHub profile. Include the affected path and a minimal reproduction. The repository owner should rotate any real credential before removing the file, because deleting a Git object does not invalidate a leaked key.

# DeepSeek V4.1 Flash 套餐复杂实测

[![validate](https://github.com/qinglong404/deepseek-v4-flash-plan-benchmark/actions/workflows/validate.yml/badge.svg)](https://github.com/qinglong404/deepseek-v4-flash-plan-benchmark/actions/workflows/validate.yml)

这是一次针对 **OpenCode Go** 与 **Command Code GOAT** 标准 DeepSeek V4.1 Flash 路由的端到端比较。测试覆盖复杂代码、高低思考档、长上下文、多文件工具调用、短任务与并发，并在同一台机器、同一 Magpie 环境、同一组题目和验收器下执行。

> **结论仅适用于本次网络、账号状态、时间窗口和合成题库。** 两边底层模型名称相同，但套餐路由、排队、思考预算、格式习惯和工具行为不同；本仓库比较的是套餐实际交付体验，不是模型权重排行榜。

## 主要结果

| 指标 | OpenCode Go | Command GOAT |
|---|---:|---:|
| high 首轮严格通过 | 28/36 · 77.8% | 15/36 · 41.7% |
| high 反馈一次后严格通过 | 32/36 · 88.9% | 20/36 · 55.6% |
| low 首轮严格通过 | 62.5% | 37.5% |
| high 有效完成数/分钟 | **0.2795** | 0.1072 |
| 长上下文完整 JSON | 11/12 | **12/12** |
| 工具流程最终通过 | 6/6 | 6/6 |

综合指标固定为：

```text
有效完成数/分钟 = 60 × 成功任务数 ÷ 实际模型请求等待秒数之和
```

失败等待和规定的一次修复均进入分母。以 12 个代码合同等权，GOAT/Go 的严格有效完成效率比为 **0.383**，配对合同 bootstrap 的 95% 区间为 **0.241–0.571**。删除任一代码合同后，比值仍为 **0.342–0.424**。

统一按低峰标准 Flash 价格及每边 $100 模型等值额度推算：

- OpenCode Go：每 $100 约 **6,742** 个合格工作流，区间 4,344–10,322。
- Command GOAT：每 $100 约 **2,426** 个合格工作流，区间 1,429–3,915。
- 只使用两边都已知完整成本的同一批题次时，GOAT/Go 为 **0.339 [0.197, 0.524]**。

这些数字是公开单价下的合成任务等值模型，不是账单、剩余额度或未来价格承诺。

## 如何解释

1. **严格评分是主结果。** 原始回答必须直接满足代码输出、运行安全和工具合同。
2. **去框只是事后诊断。** 只允许剥掉覆盖整条回答的单个 Python/py/无语言代码框，再使用同一隔离验收器；不修改算法、不挑代码块。
3. **589 条代码断言和 102 条仓库断言不是独立样本。** 主区间先在同一合同内处理重复，再以 12 个合同等权重采样。
4. **长上下文和工具结果单独报告。** 每组九个 JSON 字段相关；最终源码正确与整个工具流程成功也分别统计。
5. **本地已有不对称负载。** 期间本机日志观察到 100 次 OpenCode 同模型后台调用、GOAT 为 0；测试者另报告其他电脑可能同时使用 OpenCode。外机负载无法精确量化，因此速度描述为真实负载下的观察，并保留并发混杂。

即使假设客户端会自动去框并提前结束，GOAT/Go 的有效完成效率仍为 **0.653 [0.465, 0.866]**，同额度任务数比为 **0.687 [0.527, 0.901]**。格式兼容性改善了差距，但没有改变本次方向。

## 数据范围

- 复杂代码 high：每边 12 合同 × 3 次，共 72 条配对题次。
- 复杂代码 low：每边 12 合同 × 2 次，共 48 条配对题次。
- 长上下文：每边 12 组，实际输入覆盖约 20K、76K、194K、394K token。
- 多文件工具：每边 6 个完整 episode，共 12 个。
- 短任务与并发：每边 12 次串行，以及并发 1/2/4 各 2 批。
- 客户端请求：321 条终端记录；另有 2 条采集器中断导致的缺失客户端终态，保留为未知并经网关 499 证据作行政恢复。未将未知用量按零计费。
- 统计区间：固定种子、10,000 次合同级配对 bootstrap。

完整口径、失败标签、逐题记录和敏感性分析见[完整中文报告](report/DeepSeek套餐扩展实测报告.md)及[分析方法](data/ANALYSIS_README.md)。

## 本地复核

仓库级一致性检查只使用 Python 标准库，不访问网络，也不调用模型：

```bash
python3 scripts/validate_release.py
```

从冻结记录重新计算离线统计：

```bash
cd benchmark
python3 analysis.py --draws 10000
python3 quantity.py --draws 10000
python3 trajectory.py
```

重新执行统计会更新生成时间和文件哈希；`run_*.py` 采集脚本会真实消耗套餐额度，它们仅作为证据保留。实时采集需要显式设置：

```bash
export MAGPIE_CONFIG=/path/to/opencode.jsonc
# 或
export MAGPIE_BASE_URL=http://127.0.0.1:PORT/v1
export MAGPIE_API_KEY=your-local-gateway-key
```

本仓库不包含 API 密钥、账号 ID、账单信息、本机绝对路径或思考正文，只保留思考 token 计数。

## 时间、价格与限制

公开套餐和 token 价格核验日期为 **2026-11-05**。当时两边基础月费均为 $10；GOAT 另列支付手续费；仅使用标准 DeepSeek V4.1 Flash 时，月度等值额度均为 $100，5 小时/周窗口对应 $20/$50。下月规则可能变化。

本次主要位于低峰时段，high 为预先冻结主实验，low 和去框检查是观察早期结果后追加的补充层。题库由 12 个复杂代码合同、4 个上下文档和 2 个合成仓库组成，不能代表所有真实项目。测试未修改订阅、支付、网络或厂商配置。

本仓库无额外开源许可证，内容仅供查看和复核；第三方模型、产品名称和服务条款归各自权利人所有。详见 [NOTICE.md](NOTICE.md)。
